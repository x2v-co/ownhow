LOCAL-FIRST · OPEN SOURCE · MVP

Own how
your AI works.

Your tools. Your corrections. Your methods.

OwnHow is a local-first prototype for owning and improving how AI completes work. Understand the Skills your agents can see, choose methods with clear reasons, and turn repeated corrections into Personal Methods you control.

Get started ↗ View on GitHub ↗

No required cloud account. No model calls in governance commands. Telemetry off by default.

FROM DISCOVERY TO IMPROVEMENT

Make your workflow explainable.

01 / DISCOVER

Know what is available

Inventory Plugins and Skills across Codex, Hermes, Claude Code, Pi, OpenCode, OpenClaw, and Skywork. Discovery, installation, visibility, and actual usage stay separate; unknown evidence stays unknown.

02 / CHOOSE

Understand the selection

Resolve tasks with deterministic selection reasons. Review overlapping Skills, name and write collisions, artifact and permission findings, and a suggested smaller Skill library.

03 / RECORD

Keep evidence of outcomes

Save local receipts with outcomes, verification evidence, and corrections. Recover receipts from remote agents through reviewable bundles and an explicit acceptance step.

04 / IMPROVE

Make corrections your own

Turn explicit corrections into reviewable proposals. Apply Personal Method overlays with your approval, keep version history, and roll back without rewriting upstream packages.

Runtime-aware discovery follows each host’s available evidence. Skywork supports directory candidates and host session manifests. See the MVP boundaries.

START LOCALLY

A small CLI. A personal loop.

Requires Node.js 22 or newer. Local python3 with matching bytecode support enables PEP 552 source-hash verification; unavailable verification is reported as unknown.

Install the CLI

npm install --global github:x2v-co/ownhow#v0.9.0
ownhow --help

Connect your agent

Choose an optional Plugin or standalone Skill. Commands below are copied from the README.

Codex Plugin 
codex plugin marketplace add x2v-co/ownhow --ref v0.9.0
codex plugin add ownhow@x2v

Start a new Codex chat after installation.

Hermes Skill 
hermes skills install https://raw.githubusercontent.com/x2v-co/ownhow/v0.9.0/skills/ownhow-governance/SKILL.md --yes
Claude Code Plugin 
claude plugin marketplace add x2v-co/ownhow
claude plugin install ownhow@x2v --scope user

Start a new Claude Code session after installation.

Pi Package 
pi install git:github.com/x2v-co/ownhow@v0.9.0
OpenCode Skill 
git clone --branch v0.9.0 --depth 1 https://github.com/x2v-co/ownhow.git ~/.local/share/ownhow
ln -s ~/.local/share/ownhow/skills/ownhow-governance ~/.config/opencode/skills/ownhow-governance
OpenClaw Skill 
git clone --branch v0.9.0 --depth 1 https://github.com/x2v-co/ownhow.git ~/.local/share/ownhow
openclaw skills install ~/.local/share/ownhow/skills/ownhow-governance --global --as ownhow-governance

Governance commands do not upload source files or modify installed Plugins and Skills. The explicit updater can replace the selected OwnHow CLI and standalone Skill.

中文简介

让 AI 的工作方法，掌握在你手中。

OwnHow 是一个本地优先的原型工具：梳理不同 AI 助手中的插件与技能，解释任务选择与冲突，记录有证据的工作结果，并把你明确提出的纠正转化为可审阅的个人方法。

每次应用都需要明确批准，保留版本历史，不改写上游插件与技能。无需云端账号，遥测默认关闭。安装命令见上方，完整使用说明请阅读 README。
